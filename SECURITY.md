# Security Policy

## Supported Versions

Security updates are applied to the default branch (`main`). Only the `main` branch receives security fixes; no versioned release lines are maintained.

| Branch | Supported          |
| ------ | ------------------ |
| `main` | :white_check_mark: |
| other branches | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, use [GitHub Security Advisories](https://github.com/Microsoft-NVIDIA/CATHLEEN-ANN-TICO-/security/advisories/new) to submit a private report.

When reporting, please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or proof-of-concept code
- Affected files or components, if known

You can expect an acknowledgement within **5 business days**. If a reported vulnerability is accepted, we will work toward a fix and coordinate disclosure. If it is declined, we will provide a brief explanation.
